# Презентации лекций

Все презентации лекций можно найти
[здесь (google docs)](https://drive.google.com/drive/folders/1HW3L7kH4oBmQg5DAqOs6T9PWw9dV-BHI?usp=sharing)

## Содержание

0. [How This Course is Organized](https://docs.google.com/presentation/d/1WAU6NxRCGAWxsrXuFuXIpn-hwl01eiSCQFkCjUMnNOc/edit?usp=drive_link) -
содержимое курса, формат работы, условия оценки
1. [Hello, World!](https://docs.google.com/presentation/d/1xxLAE6ugPN7tirpJ7y3_6kVwfvChA-riFZ-O_-Kl1p8/edit?usp=drive_link) -
программа "Hello, World!", реализация языка программирования, IDE
1. [How to Solve Homework](https://docs.google.com/presentation/d/1hTvBkABn93dzPgstwj8EforujZTJecaFbPoKVjtYL8M/edit?usp=drive_link) -
руководство по сдаче решений практических заданий
1. [History of the C Programming Language](https://docs.google.com/presentation/d/1WseH9i3YTemH5taCFl1bMqzy02D43ZATybK19tN3Efw/edit?usp=drive_link) -
история языка программирования Си, цель создания, виды поведения программ
1. [Data Storage](https://docs.google.com/presentation/d/1kP7lFv9tLetxEwQo400JcTPGm9o-uZoANd7kjiCDAZs/edit?usp=drive_link) -
хранение данных, биты и байты, адресное пространство
1. [Data Types and Encoding](https://docs.google.com/presentation/d/1DgeZ6dyJYLTG7kWbNLScxhs0tPwIn_SagXm4iJF0uQ8/edit?usp=drive_link) -
типы данных, размеры типов, проблемы и способы кодировки данных
1. [Integer Types](https://docs.google.com/presentation/d/1QRjd_NWz3vZ8iBknAl3jqD5fIsNlNNKRlgUZWAa1Y8s/edit?usp=drive_link) -
целые типы данных
1. [Standard Screwdriver Set](https://docs.google.com/presentation/d/1ktmn66ycyXiftFp4O8xnvSX61KxrTENhcDHnZrI7Y6U/edit?usp=drive_link) -
базовый набор инструментов (функция **main**, глобальные переменные, ввод и вывод данных, операторы)
1. [Functions](https://docs.google.com/presentation/d/1MZwKQZCV5jVB1vMoIUsBDYKzz4BSHVB5d92W6ddo1w0/edit?usp=drive_link) -
функции, локальные переменные, параметры, возвращаемые значения, стек вызовов, детали реализации
1. [Pointers](https://docs.google.com/presentation/d/1nZrBSjzkAZd9NGGD3QnfFKz4ROHaOsMyGU_8d3WY-6k/edit?usp=drive_link) -
указатели, передача параметров по адресу, значения указателей
